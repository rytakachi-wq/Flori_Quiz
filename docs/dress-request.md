# 着せ替えパーツ 作成依頼書(ChatGPT 用)

頭 25 + 体 25 + 顔 10 = **60 パーツ**。ChatGPT は 1 日 3 枚までなので、**1 枚に複数パーツを並べた「シート」**で作る(全 5 枚・2 日)。

| 日 | 枚 | 中身 | 個数 |
|---|---|---|---|
| 1 日目 | ① | 頭 A(頭 1〜13) | 13 |
| | ② | 頭 B(頭 14〜25) | 12 |
| | ③ | 体 A(体 1〜13) | 13 |
| 2 日目 | ④ | 体 B(体 14〜25) | 12 |
| | ⑤ | 顔(顔 1〜10) | 10 |

## 使い方
1. ChatGPT に **`assets/flori/wave_smile.png`**(フロリの絵)を添付する。「大きさと形の基準」として使う(フロリは描き直させない・シートに入れさせない)。
2. 下の **【共通ルール】** を貼る。続けて、その日の **【シートの指示】** を貼る。
3. 2 枚目以降も、毎回【共通ルール】から貼る(会話が長いと忘れるため)。絵柄をそろえるため、**同じ会話で続ける**。
4. 出てきたシートは、画面の小さい絵ではなく、**ダウンロードした元ファイル**を `assets/dress/new/` に置いてください(`head_A.png`、`head_B.png`、`body_A.png`、`body_B.png`、`face.png`)。小分けはせず、切り出しと配置は、こちらで行う。

## 【共通ルール】(毎回貼る)

```
添付の「フロリ」(宇宙服のような白い丸いヘルメット頭と、ずんぐり丸い体のロボット)に着せるための、「着せ替えパーツ」のイラストを作ってください。
パーツは、プログラムでフロリの絵の上に「そのまま貼り付ける」だけです。画像を加工・合成し直すことはできません。次のルールを必ず守ってください。

■ 一番大切なルール(裏側を描かない)
- 正面から見た絵だけ。パーツの「裏側・内側・背中側」は描かない。
  例:マフラーは、首の後ろに回る部分を描かない。バッグは、背中側のひもや、後ろに隠れる部分を描かない。帽子は、頭の後ろ側のつばや、内側を描かない。
- フロリの体に隠れる部分が出ないように、パーツ 1 つだけで「完成した形」にする(端がちゃんと閉じている、ひもが体の後ろへ消えない)。
- 肩ひも・首ひも・あごひもは描かない(必要なら、前から見える短い飾りだけ)。
- 翼・マント・リュックなど、体の後ろに回る物は作らない。

■ フロリの形に合わせる
- フロリは「横長でずんぐり」。頭(ヘルメット)は横に広い丸型で、首はない。体は丸くて太い。足と腕は短い。
- 頭用パーツ:ヘルメットのてっぺんに「のせる」形。下側は、ヘルメットの丸いカーブに合わせてゆるい弧にする。横幅はヘルメットの 30〜90% くらい。
- 体用パーツ:胸〜おなかの、横に広い範囲に付ける形。縦長・細長は避け、横長〜ずんぐりにする。幅は体の 30〜90% くらい。
- 顔用パーツ:ヘルメットの「暗いグレーの顔の画面」の上に重ねる。画面は暗いので、明るい色(白・黄色・ピンク・水色)を使い、濃い色だけの絵にはしない。

■ 絵柄
- フロリに合わせる:太めのやわらかい輪郭線(青みのあるダークグレー)、ふんわりした塗り、パステル寄りのやさしい色、角が丸い、かわいい。子ども向け。
- 全部のパーツで線の太さ・タッチ・色合いをそろえる。
- 文字・ロゴ・有名キャラクター・ブランドは入れない。

■ シートの作り方
- 背景は、まっさらな真っ白(#FFFFFF)の無地にする。影・光のにじみ・ぼかし・グラデーションは、パーツの外側には一切入れない。パーツの輪郭線は、はっきり閉じる(背景を自動で抜くため)。
- 出力は、「1 枚の画像」にする。パーツごとに小分けにしたり、複数の画像に分けたりしない(切り出しはこちらで行う)。
- 画像の大きさは、できるだけ大きく(長辺 2000px 以上)。縮小・圧縮しない。
- 1 つのパーツは、他のパーツと絶対に重ならない・くっつかない。パーツの間は広く空ける。
- 影・地面・光のにじみ・枠線・番号・文字は入れない(パーツだけ)。
- 格子状(4 列 × 4 行)に並べ、左上から右へ、上から下へ、番号順に置く。使わないマスは空欄。
- 各パーツは、そのパーツが入るマスの 70〜90% の大きさに、中央に置く。はみ出さない。
- 高解像度で。
```
