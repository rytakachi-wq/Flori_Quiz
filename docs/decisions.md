## 追加の決定(その4:音)

- BGMは場面ごとに1曲:表紙・せいせき・せってい=Slime Time、ふつうの問題=Ticketless、オニ問題=Swan Lake Theme、結果発表=Swan Lake Theme(曲が3つなので、オニ問題と結果は同じ。最初は表紙とオニ問題が逆だったが、利用者の依頼で入れかえた)。
- 効果音:ボタンをおしたとき=決定ボタン、せいかい=ドアチャイム、ふせいかい=クイズ不正解。
- せってい:BGMと効果音の大きさを、0〜100のつまみで変えられる(0で音が出ない)。大きさは端末内に保存する(個人情報ではない)。はじめは、BGM 70、効果音 80。
- ブラウザの決まりで、画面を1回さわるまでは音が出ない。表紙には「画面をクリックすると、おんがくが ながれるよ」と出し、さわったら消す。BGMが止まっていたら、画面をさわるたびに流しなおす。ほかのタブに切りかえても、BGMは止めない(止めると、見えている画面でも止まる場合があったため)。
- 音量の決め方(音量を変えすぎると、聞こえなくなったり大きすぎたりしたため直した):
  - つまみ(0〜100)を、0 dB〜-30 dB に均等にわりあてる(耳は、音量の倍率ではなく、デシベルで大きさを感じるため)。0 のときは、BGMを止めずに音量だけを0にする(止めたり流したりをくり返すと、流れなくなることがあった)。
  - 測ったところ、BGM3曲は平均の大きさが -10.8〜-13.5 dB と大きく、曲ごとに差があり、効果音(-23〜-26 dB)より大きかった。そこで、BGMを曲ごとに、つまみ100のとき -19 dB にそろえ(最初は -16 dB だったが、BGMが大きいという声で、3 dB 下げた)、小さい効果音(ボタン音・不正解)はもち上げた(ボタン音は、小さいという声で、1.7倍から2.4倍に上げた)(`src/audio.js` の BGM_GAIN と boost)。曲を入れかえたら、測りなおす。
- 問題を解いているときも、画面上の「せってい」ボタンから、音の大きさを変えられる(表紙のせっていと、同じ大きさを使う)。開いているあいだは、数字キーで回答できない。
- 音のファイルは `assets/audio/`。曲の利用条件(クレジット表記の要否など)は未確認なので、利用者が確認する(`assets/audio/README.md`)。

## 追加の決定(その5:総合得点)

「4回(20問)の記録が100点満点」と「全40問(ふつう35問+オニ5問)」がくいちがうため、100点満点を、全問題の総合得点に1本化した。

- 総合得点(100点満点):ふつうの問題35問で95点、オニ問題5問で5点(1問1点)。
  - ふつうの問題:一度でも正解した問題の数 × 95 ÷ 35(四捨五入)。
  - オニ問題:一度でも正解した問題1問につき1点。
  - 一度正解した問題は、ずっと残る(何度正解しても、同じ問題は1回ぶん)。
- 成績の満点は、いつでも「100点満点」と見せる。ふつうの問題だけでは95点までしか取れないので、「まだ何かある」と、うっすら感じさせる。成績の画面には、オニ問題のことや、40問という数は、出さない(出会った問題・正解した問題は「○ / 35問」)。
- 「20問(4回分)の記録」(今の20問、20問の最高、20問を終えた回数)は、やめた。4回遊ぶと、難しさのカウンターと出した問題の記録を、最初に戻す動きは、そのまま。
- オニ問題の結果:「遊んだ回数」「解いた問題」「正解率」「最高得点(1回)」には入れない。はじめて正解した問題の分だけ、総合得点に入る(結果画面に「総合得点が○点ふえたヨ」と出す)。
- せってい画面には、オニ問題や得点のことを出さない(音の大きさだけ)。
- 保存するもの:正解したことのあるオニ問題の番号(`oniRight`)を足した。

## 追加の決定(その8:漢字表記とふりがな)

- 表記:画面の文字(問題、選択肢、解説、ボタン、案内)の、ひらがな表記を、漢字にした。使う漢字は、中学までに習う常用漢字。常用漢字にない字(猫・鼠・蝋燭・紐・林檎・賑・蛙 など)は、ひらがな・カタカナのままにした。
- ふりがな設定(設定の画面と、問題を解いている途中の設定の、どちらからも変えられる):
  - すべての漢字にふりがな(はじめの設定)
  - 中学以降に習う漢字だけ(小学校で習う漢字には、ふりがなをつけない)
  - ふりがななし
  - 利用者の指定は「高校以降」だったが、問題の漢字は中学までなので、scheme.md の「中学以降」にした(確認済み)。
- 設定は、端末内に保存する。
- 仕組み:画面に文字が出るたびに、漢字を含む文字に `<ruby>` をつける(`src/furigana.js`)。読みは `src/furigana-data.js` の辞書(漢字1字ごとの標準の読み+熟語・文脈で変わる読みの例外)。数字といっしょの数え方(3本・24分・7日・2人 など)は、読みの変わり方を、プログラムで決めている。
- 辞書の読みは、読みを自動でつけるツール(Python の pykakasi)で下書きを作り、画面に出る全部の文章に当てはめて、一つずつ確認して直した。ツールは、開発のときだけ使い、アプリには入れていない。
- 辞書にない漢字には、ふりがながつかない。新しい漢字を使うときは、辞書に読みを足す。

- **「つづきから」**は、どちらのモードにもある(難しさのカウンターと、もう出した問題を保存)。表紙のボタンの下の小さな文字は「難しさ ★☆☆☆」「つづきから ・ ★★★☆」のように、4段階の星で見せる。クイズ中の「難しさ」も、4段階の星。
- **みんなで対戦**は、これまでどおり、段階1・2・3の問題から出す(回戦=段階)。ふつう+難しいの問題の中から選ぶ。
- **「易しい」の漢字を使わない**:画面の文字は、ひらがな「やさしい」「やさしく」にした(リラックスのボタン「やさしい(3×3)」、結果画面の知らせ)。
- 点数・総合得点は、そのまま(ふつう+難しいの50問を、問題ごとの最高点で足して100点)。


## 追加の決定(その32:おさらい・読み上げ・ほか)

- **おさらい**:まちがえた問題に加えて、**ヒントを見て解いた問題**も入る(ヒントなしで正解すると、消える)。「おさらい」を押すと、制限時間をたずねる窓に、「まちがえた問題と、ヒントを見て解いた問題が出ます」という説明を出す。
- **難しさの下がりかた**:正解で+1、まちがえで−1(0まで)。3たまると1段階上がる。たまりすぎないように、上限は4にした(上の段階にいるときは、**多くても2問まちがえると、下の段階にもどる**)。
- **読み上げ**:ヒントと、答えたあとの「正解・解説」も読む。声が出ないことがあったので、日本語の声を選び、読みはじめを少し待つようにした。設定で「問題を自動で読み上げる」にチェックを入れたとき、クイズ画面に「🔊 読み上げ」ボタンを出す(押すと、いまの問題・ヒント、答えたあとは解説を、もう一度読む)。
- **オープニング**:音の準備が終わる前に曲を鳴らそうとして、鳴らずに終わることがあった。準備が終わってから鳴らすようにした。
- **表紙のオープニング戻り**:20秒 → 30秒にもどした。
- **リラックスのヒント**:説明を閉じても、光った木は、光ったまま。
- **設定のフロリ**を大きくした(高さ約1.5倍)。
- **みんなで対戦のルール**を、3回戦のカード(星・点数つき)と、絵つきの短い説明にした。
- **ふりがなの見直し**:全問題と、全画面の文字で、読みの抜けと、小学校の漢字へのふりがなが、ないことを確かめた。
- **読み直しで、制限時間が止まらない不具合**:「読み上げ」ボタンで読み直すと、前の声が止まった知らせが、あとから届いて、時間が動きだしていた。いまの声の知らせだけで、時間を止めたり動かしたりするようにした。
