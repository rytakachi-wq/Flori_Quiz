## 追加の決定(2026-10-08)

- 得点:1問5点。5問だけ遊んだ回の満点は25点、20問通しの満点は100点。
- 難しさの段階:カウンター0〜2が段階1、3〜5が段階2、6〜8が段階3、9以上が段階4。
- フロリの表情:顔だけの4種を、手を振る全身画像の画面部分にはめ込んで使う(`assets/flori/wave_*.png`)。
- 保存:最高得点のみ(端末内)。途中経過は保存しない。個人情報は集めない・ログイン不要。
- 20問の使い方:全20問を1回ずつ出す(4回で重ならない)。20問(4回分)が終わったら、カウンターを0から数え直す。
- 問題の並び:20問を5問ずつ4回に分ける。難しさのカウンターで出す問題を選ぶ。

- 技術:HTML・CSS・JavaScript のみ(ビルドなし、外部ライブラリなし)。ブラウザで動く。
- 段階の問題が足りないとき:いちばん近い段階の問題で補う(同じ近さなら下の段階を先に使う)。20問は4回で重ならない。
- 表情の出し分け:表紙は手を振る全身、出題中は本とペン、正解は笑顔、不正解は><、段階が上がった問題は驚き、結果は にっこり。

- 公開:GitHub Pages(`rytakachi-wq/Flori_Quiz` の `main` ブランチの直下)。URL は https://rytakachi-wq.github.io/Flori_Quiz/ 。更新は `main` に push するだけで、1〜2分で反映される。リポジトリは公開(誰でも中身を見られる)。
