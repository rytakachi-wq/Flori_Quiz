# 音(BGM と効果音)

利用者が用意した音。元のファイル名と、使っている場面は次のとおり。場面とファイルの対応は `src/audio.js` の先頭で決めている。

## BGM

**いまは、BGMの曲はありません(差しかえ中)。** 前の3曲(Artlist の曲)は、利用条件の問題で、外しました(下の「利用条件」を参照)。新しい曲は、利用条件が確認できたものだけを入れます。入れるときは、曲のファイルをこのフォルダに置き、`src/audio.js` の先頭の `BGM` に、場面ごとのファイル名を書きます。

## 利用条件(調べた結果。重要)

**BGM3曲は、「Artlist」(有料の音楽サービス)の曲です。** ファイルの中の情報に、次のように書かれています。

| ファイル | 中の情報 |
|---|---|
| `bgm-swan-lake.mp3` | Swan Lake Theme(Kashido)/ Licensed for video by Artlist.io |
| `bgm-ticketless.mp3` | Ticketless by Arcade / All Rights Reserved to www.Art-list.io |
| `bgm-slime-time.mp3` | Sugar Rush by Playtime Paradise / All Rights Reserved to www.Art-list.io |

(元のファイル名の作者名と、ファイルの中の曲名が、一部ちがう。)

Artlist の利用許諾(https://help-center.artlist.io/privacy-terms/artlist-license)では、
- 音楽は、映像などの作品の一部として使うことだけが認められる。
- 音声ファイルだけを、ほかの人が取り出せる形で公開することは禁止。
- アプリやゲームへの組み込みは、標準の許諾の範囲外で、別の契約(エンタープライズ契約)が必要。
- 許諾は、契約した本人だけのもの。

そのため、**公開リポジトリ・公開サイトに3曲を置いておくことは、許諾の範囲をこえている可能性が高い。** 使い続けるなら、Artlist に問い合わせる(エンタープライズ契約)か、ゲームでの利用と再配布が認められている別の曲に差しかえる。

**効果音3つ**は、ファイルの名前などから「効果音ラボ」の素材と見られるが、ファイルに書かれていないので、確認できていない。効果音ラボの規約では、ゲームやアプリに組み込んで使うのは無料で、クレジットも要らない。ただし、素材のファイルを、そのまま配ることは禁止されている。
