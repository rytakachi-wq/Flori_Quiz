# 音(BGM と効果音)

利用者が用意した音。元のファイル名と、使っている場面は次のとおり。場面とファイルの対応は `src/audio.js` の先頭で決めている。

## BGM

| ファイル | 元のファイル名 | 使う場面 |
|---|---|---|
| `bgm-swan-lake.mp3` | Kashido - Swan Lake Theme.mp3 | オニ問題、結果発表 |
| `bgm-ticketless.mp3` | Francesco DAndrea - Ticketless.mp3 | ふつうの問題を解いているとき |
| `bgm-slime-time.mp3` | Randy Sharp - Slime Time.mp3 | 表紙・せいせき・せってい |

## 効果音

| ファイル | 元のファイル名 | 使う場面 |
|---|---|---|
| `se-button.mp3` | 決定ボタンを押す3.mp3 | ボタンをおしたとき |
| `se-chime.mp3` | ドアチャイム1.mp3 | せいかい、せっていの効果音の大きさをかえたとき |
| `se-wrong.mp3` | クイズ不正解1.mp3 | ふせいかい |

## 利用条件(要確認)

3つのBGMは、作者名つきの曲。入手元と、公開してよいか(クレジット表記が必要か)を、利用者が確認する。この条件が分かったら、ここに書く。リポジトリを公開すると、これらの曲も誰でも取り出せるようになる。
