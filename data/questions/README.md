# 問題データ

- `questions.md` は人が読むための一覧(問題・選択肢・正解・解説)。確認用で、元データは `questions.json`。
- `questions.json` に全40問(ふつうの問題35問+オニ問題5問)。独自に作ったひらめき問題で、日常知識中心。各問題に解説つき。
- 漢字は中学で習う範囲まで。

## 段階ごとの問題数(決まった数ではなく、いまの内訳)

記述式の問題:q08・q20・q26

| 段階 | 問題数 | 内容 |
|---|---|---|
| 1 | 10 | 子ども向け(ひらめき、国語、社会、理科)。q01〜q10 |
| 2 | 10 | 少し考える(ひらめき、論理、国語、社会、理科)。q11〜q20 |
| 3 | 10 | 大人でも考える(ひらめき、論理、国語、社会、理科)。q21〜q30 |
| 4 | 5 | 難問(論理、数の計算、時計、橋わたり)。q31〜q35 |
| 5 | 5 | オニ問題(表紙のすみのフロリを5回押すと出る)。o01〜o05 |

## 形式

| 項目 | 内容 |
|---|---|
| `id` | 問題の番号(q01〜q35、オニ問題は o01〜o05)。段階が低い順に並べ、段階を変えたときは番号もつけなおす |
| `level` | 段階(1〜4、オニ問題は5) |
| `type` | 回答の形式。`choice`(選択肢)か `text`(記述式) |
| `category` | 国語・社会・理科・英語・図工・規則・論理・数・科学・日常・ひらめき・オニ |
| `text` | 問題文 |
| `choices` | 選択肢(4つ)。`choice` のとき |
| `answer` | 正解の選択肢の番号(0から数える)。`choice` のとき |
| `answers` | 認める答えの一覧(最初が、画面に出す正解)。`text` のとき。全角・半角、大文字・小文字、ひらがな・カタカナ、空白や記号のちがいは無視して判定する |
| `explanation` | 解説 |

決定事項は `docs/decisions.md` 参照。
