# 問題データ

- `questions.md` は人が読むための一覧(問題・選択肢・正解・解説)。確認用で、元データは `questions.json`。
- `questions.json` に全20問。独自に作ったひらめき問題で、日常知識中心。各問題に解説つき。
- 漢字は中学で習う範囲まで。

## 段階ごとの問題数

| 段階 | 問題数 | 内容 |
|---|---|---|
| 1 | 6 | 子ども向け(ひらめき、国語、社会、理科)。q01〜q06 |
| 2 | 5 | 少し考える(ひらめき、論理、規則、科学、理科)。q07〜q11 |
| 3 | 5 | 大人でも考える(ひらめき、論理、理科)。q12〜q16 |
| 4 | 4 | 難問(論理、数の計算、時計)。q17〜q20 |

## 形式

| 項目 | 内容 |
|---|---|
| `id` | 問題の番号(q01〜q20)。段階が低い順に並べている |
| `level` | 段階(1〜4) |
| `type` | 回答の形式。今は `choice`(選択肢)のみ。入力式を足すときは別の値を追加する |
| `category` | 国語・社会・理科・英語・図工・規則・論理・数・科学・日常・ひらめき |
| `text` | 問題文 |
| `choices` | 選択肢(4つ) |
| `answer` | 正解の選択肢の番号(0から数える) |
| `explanation` | 解説 |

決定事項は `docs/decisions.md` 参照。
