# 問題データ

- `questions.md` は人が読むための一覧(問題・選択肢・正解・解説)。確認用で、元データは `questions.json`。
- `questions.json` に全40問(ふつうの問題35問+オニ問題5問)。独自に作ったひらめき問題で、日常知識中心。各問題に解説つき。
- 漢字は中学で習う範囲まで。

## 段階ごとの問題数(決まった数ではなく、いまの内訳)

| 段階 | 問題数 | 内容 |
|---|---|---|
| 1 | 10 | 子ども向け(ひらめき、国語、社会、理科、英語)。q01〜q06、q21〜q24 |
| 2 | 10 | 少し考える(ひらめき、論理、国語、社会、理科)。q07〜q11、q25〜q27、q29、q34 |
| 3 | 10 | 大人でも考える(ひらめき、論理、社会、理科)。q12〜q16、q28、q31〜q33、q35 |
| 4 | 5 | 難問(論理、数の計算、時計、橋わたり)。q17〜q20、q30 |
| 5 | 5 | オニ問題(表紙のすみのフロリを5回押すと出る)。o01〜o05 |

## 形式

| 項目 | 内容 |
|---|---|
| `id` | 問題の番号(q01〜q35、オニ問題は o01〜o05)。q21 以降は、あとから追加した問題 |
| `level` | 段階(1〜4、オニ問題は5) |
| `type` | 回答の形式。今は `choice`(選択肢)のみ。入力式を足すときは別の値を追加する |
| `category` | 国語・社会・理科・英語・図工・規則・論理・数・科学・日常・ひらめき・オニ |
| `text` | 問題文 |
| `choices` | 選択肢(4つ) |
| `answer` | 正解の選択肢の番号(0から数える) |
| `explanation` | 解説 |

決定事項は `docs/decisions.md` 参照。
