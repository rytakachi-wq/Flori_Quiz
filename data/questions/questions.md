# 問題一覧(確認用)

`questions.json` から作った、人が読むための一覧。直すときは `questions.json` を直し、この一覧も作り直す。

番号は問題の番号。段階が低い順に並んでいる(段階を変えたときは、番号もつけなおす)。「記述式」の問題は、選択肢がなく、答えを書いて入力する。

## ふつうモード 段階1(子ども向け)

### 1. 水1滴と水1滴を、くっつけると、水は何滴になる?
*q01 / ひらめき / 選択式*

- A. 0滴
- B. 1滴
- C. 2滴
- D. 3滴

**正解:B. 1滴**

解説:水滴は、くっつくと、1つの大きな水滴になります。1+1が、いつも2になるとは限らない、というひらめきの問題です。

ヒント:「1+1が、いつも2になる」とは限らないヨ。水の粒がくっつくところを、思いうかべてみよう。

### 2. 海に面していない県は、次のうちどれ?
*q02 / 社会 / 選択式*

- A. 新潟県
- B. 長野県
- C. 福井県
- D. 千葉県

**正解:B. 長野県**

解説:長野県は海に面していません。海に面していない県は、栃木・群馬・埼玉・山梨・長野・岐阜・滋賀・奈良の8県です。

ヒント:海がない県は、日本の真ん中あたり、山が多い地域にあるヨ。

### 3. 晴れた日の正午ごろ、地面にできる影の長さは、朝や夕方と比べてどうなる?
*q03 / 理科 / 選択式*

- A. 朝や夕方より短い
- B. 朝や夕方より長い
- C. 朝や夕方と同じ
- D. 影はできない

**正解:A. 朝や夕方より短い**

解説:正午ごろは太陽が一番高い位置にあるので、影は1日のうちで一番短くなります。朝や夕方は太陽が低いので、影が長く伸びます。

ヒント:影は、太陽が高いところにあるほど、短くなるヨ。太陽が一番高いのは、何時ごろかな?

### 4. ろうそくが5本、火がついています。風が吹いて、2本の火が消えてしまいました。ろうそくは、全部で何本残っている?
*q04 / ひらめき / 選択式*

- A. 3本
- B. 5本
- C. 2本
- D. 0本

**正解:B. 5本**

解説:消えたのは「火」だけで、ろうそく自体はなくなっていません。火がついているのは3本ですが、ろうそくは5本残っています。

ヒント:問題文を、よく読もう。消えたのは、何かな?

### 5. かけっこの最中に、あなたは2番目を走っていた人を抜きました。あなたは今、何番目?
*q05 / ひらめき / 選択式*

- A. 1番目
- B. 2番目
- C. 3番目
- D. 4番目

**正解:B. 2番目**

解説:2番目の人を抜くと、その人の場所に入れ替わります。だから、あなたが2番目で、抜かれた人は3番目になります。1番目の人は抜いていないので、1番にはなれません。

ヒント:「抜く」と、抜いた相手と、場所が入れ替わるヨ。1番目の人は、抜いたかな?

### 6. 1本のひもを、真ん中で切ります。できたひもを全部そろえて重ね、また、真ん中で切ります。このように、合わせて3回、真ん中で切ると、ひもは何本になる?

**正解:C. 8本**

解説:1回目で2本になります。2回目は重ねて切るので、全部2つに分かれて4本。3回目も同じように2倍になって、8本です。

### 12. 2枚の硬貨があり、合計は60円です。1枚は50円玉ではありません。2枚の硬貨は何?
*q12 / ひらめき / 選択式*

- B. 10円玉と100円玉

**正解:A. 50円玉と10円玉**

解説:「1枚は50円玉ではない」は、「2枚とも50円玉ではない」という意味ではありません。もう1枚は50円玉で構いません。だから、50円玉と10円玉です。

ヒント:「1枚は50円玉ではない」は、「2枚とも50円玉ではない」という意味かな?

### 17. ある月のカレンダーで、縦に並んだ3つの日を足すと、42になりました。真ん中の日は何日?
*q17 / ひらめき / 選択式*

- B. 14日
- C. 15日
- D. 21日

**正解:B. 14日**

解説:縦に並ぶ日は、7日ずつ違います。真ん中の日を□とすると、(□-7)+□+(□+7)=□×3です。42÷3=14なので、真ん中は14日です。

ヒント:カレンダーで、縦に並ぶ日は、何日ずつ違うかな? 真ん中の日を□にして、式を作ろう。

### 24. 鏡にうつった時計が、4時50分をさしているように見えています。実際の時刻は?
*q24 / ひらめき / 選択式*

- A. 8時10分
- B. 4時50分
- C. 7時10分
- D. 5時10分

ヒント:鏡では、左右が逆になるヨ。12時から、鏡に見える時刻を引くと、実際の時刻が出るヨ。

### 32. ある2桁の数があります。十の位と一の位の数を足すと7です。十の位と一の位を入れ替えると、もとの数より27大きくなります。もとの数は?
*q32 / 数 / 選択式*

- A. 16
- B. 34
- C. 25
- D. 52

**正解:C. 25**

解説:入れ替えて大きくなるのは、一の位の方が大きいときです。差の27は9の3倍なので、一の位は十の位より3大きいと分かります。足して7で3の差になるのは2と5。もとの数は25で、入れ替えた52との差は27です。

ヒント:十の位をa、一の位をbにして、入れ替えると、何が増えるかを、式で表そう。差の27は、9の何倍かな?

## オニ問題(表紙のすみのフロリを5回押すと出る)

### オニ1. 机の上に21本の棒があります。2人が交代で、1〜3本ずつ取ります。最後の1本を取った人が勝ちです。あなたが先に取るとき、最初に何本取れば、必ず勝てる?
*o01 / オニ / 選択式*

- A. 1本
- B. 2本
- C. 3本
- D. どれでも勝てる

**正解:A. 1本**

解説:残りを、4の倍数にして相手に回すと、相手が何本取っても、あなたが合計4本になるように取れます。21本から1本取って20本にすれば、必ず最後の1本を取れます。

### オニ2. 1番から100番までの扉が、全部閉まっています。
100人が順番に、扉を、開いていれば閉め、閉まっていれば開ける動きをします。  
・1人目は、1の倍数(全部)の扉を動かす  
・2人目は、2の倍数(2、4、6…)の扉を動かす  
・3人目は、3の倍数(3、6、9…)の扉を動かす  
…100人目まで、同じように続けます。  
最後に開いている扉は、何枚?  
*o02 / オニ / 選択式*

- A. 50枚
- B. 25枚
- C. 10枚
- D. 100枚

**正解:C. 10枚**

解説:扉は、その番号の約数の数だけ動かされます。約数が奇数の扉だけが、開いたままです。それは、1、4、9…と、同じ数を2回かけた数で、100までに10個です。

### オニ3. 5人が順番に言いました。A「この中に、うそつきは1人」B「うそつきは2人」C「うそつきは3人」D「うそつきは4人」E「うそつきは5人」。本当のことを言っているのは、誰?
*o03 / オニ / 選択式*

- B. Bさん
- C. Eさん
- D. Dさん

**正解:D. Dさん**

解説:5人の言葉は、全部違う数なので、本当のことを言えるのは、多くても1人です。本当を言う人が1人なら、うそつきは4人。それを言っているのはDさんで、ほかの4人はうそになり、つじつまが合います。

### オニ4. 夜中の0時ちょうどから次の日の0時の直前までの24時間で、時計の長い針と短い針がぴったり重なるのは何回?(0時ちょうども数えます)

### オニ5. 4人が、夜に橋を渡ります。懐中電灯は1つだけで、橋は一度に2人までしか渡れません。2人で渡るときは、遅い人に合わせます。4人が渡るのにかかる時間は、1分、2分、5分、10分です。全員が渡るのに、最短で何分?

- B. 18分
- C. 19分
