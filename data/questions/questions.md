# 問題一覧(確認用)

`questions.json` から作った、人が読むための一覧。直すときは `questions.json` を直し、この一覧も作り直す。

番号は問題の番号。段階が低い順に並んでいる(段階を変えたときは、番号もつけなおす)。「記述式」の問題は、選択肢がなく、答えを書いて入力する。

## ふつうモード 段階1(子ども向け)

### 1. 水1滴と水1滴をくっつけると、水は何滴になる?
*q01 / ひらめき / 選択式*

- A. 0滴
- B. 1滴
- C. 2滴
- D. 3滴

**正解:B. 1滴**

解説:水滴はくっつくと1つの大きな水滴になります。1+1がいつも2になるとは限らない、というひらめきの問題です。

ヒント:「1+1が、いつも2になる」とは限らないヨ。水の粒がくっつくところを、思いうかべてみよう。

### 2. 海に面していない県は、次のうちどれ?
*q02 / 社会 / 選択式*

- A. 新潟県
- B. 長野県
- C. 福井県
- D. 千葉県

**正解:B. 長野県**

解説:長野県は海に面していません。海に面していない県は、栃木・群馬・埼玉・山梨・長野・岐阜・滋賀・奈良の8県です。

ヒント:海がない県は、日本の真ん中あたりの山が多い地域にあるヨ。

### 3. 晴れた日の正午ごろ、地面にできる影の長さは朝や夕方と比べてどうなる?
*q03 / 理科 / 選択式*

- A. 朝や夕方より短い
- B. 朝や夕方より長い
- C. 朝や夕方と同じ
- D. 影はできない

**正解:A. 朝や夕方より短い**

解説:正午ごろは太陽が一番高い位置にあるので、影は1日のうちで一番短くなります。朝や夕方は太陽が低いので、影が長く伸びます。

ヒント:影は太陽が高いほど短くなるヨ。太陽が一番高いのは、何時ごろかな?

### 4. ろうそくが5本、火がついています。風が吹いて、2本の火が消えてしまいました。ろうそくは、全部で何本残っている?
*q04 / ひらめき / 選択式*

- A. 3本
- B. 5本
- C. 2本
- D. 0本

**正解:B. 5本**

解説:消えたのは「火」だけでろうそく自体はなくなっていません。火がついているのは3本ですが、ろうそくは5本残っています。

ヒント:問題文をよく読もう。消えたのは、何かな?

### 5. かけっこの最中に、あなたは2番目を走っていた人を抜きました。あなたは今、何番目?
*q05 / ひらめき / 選択式*

- A. 1番目
- B. 2番目
- C. 3番目
- D. 4番目

**正解:B. 2番目**

解説:2番目の人を抜くと、その人の場所に入れ替わります。だからあなたが2番目で抜かれた人は3番目になります。1番目の人は抜いていないので、1番にはなれません。

ヒント:「抜く」と抜いた相手と場所が入れ替わるヨ。1番目の人は、抜いたかな?

### 6. 1本のひもを、真ん中で切ります。できたひもを全部そろえて重ね、また真ん中で切ります。このように合わせて3回、真ん中で切るとひもは何本になる?

解説:1回目で2本になります。2回目は重ねて切るので、全部2つに分かれて4本。3回目も同じように2倍になって、8本です。

### 14. A、B、C、Dの4人が1列に並んで体育館に入ります。次のことが分かっています。
・AさんはBさんのすぐ前にいる。  
・Dさんは先頭(一番前)にいる。  
・Cさんは一番後ろではない。

*q14 / ひらめき / 選択式*

- A. Aさん
- B. Bさん
- C. Cさん
- D. Dさん

ヒント:まず先頭の人を決めよう。「AがBのすぐ前」は2人がセットで並ぶということだヨ。

### 15. 2枚の硬貨があり、合計は60円です。1枚は50円玉ではありません。2枚の硬貨は何?

**正解:A. 50円玉と10円玉**

解説:「1枚は50円玉ではない」は、「2枚とも50円玉ではない」という意味ではありません。もう1枚は50円玉で構いません。だから50円玉と10円玉です。

ヒント:「1枚は50円玉ではない」は、「2枚とも50円玉ではない」という意味かな?

### 20. ある月のカレンダーで縦に並んだ3つの日を足すと、42になりました。真ん中の日は何日?

### 29. A、B、C、D、E、Fの6人を背が高い順に並べます。次のことが分かっています。
・AさんはFさんより高い。  
・EさんはAさんより高い。

### 31. 鏡にうつった時計が、4時50分をさしているように見えています。実際の時刻は?
*q31 / ひらめき / 選択式*

- A. 8時10分
- B. 4時50分
- C. 7時10分
- D. 5時10分

**正解:C. 7時10分**

解説:鏡では左右が逆になるので、鏡に見える時刻を12時から引くと実際の時刻になります。12時-4時50分=7時10分です。短い針は4時50分だと「4」ではなく「5」のすぐ手前にあります。「5」の反対側は「7」なので実際は8時台ではなく7時台です。

ヒント:鏡では左右が逆になるヨ。12時から鏡に見える時刻を引くと、実際の時刻が出るヨ。

### オニ1. 机の上に21本の棒があります。2人が交代で、1〜3本ずつ取ります。最後の1本を取った人が勝ちです。あなたが先に取るとき、最初に何本取れば必ず勝てる?

### オニ2. 1番から100番までの扉が、全部閉まっています。
