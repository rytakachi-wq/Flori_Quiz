# 問題一覧(確認用)

`questions.json` から作った、人が読むための一覧。直すときは `questions.json` を直し、この一覧も作り直す。

番号は問題の番号。段階が低い順に並んでいる(段階を変えたときは、番号もつけなおす)。「記述式」の問題は、選択肢がなく、答えを書いて入力する。

## 段階1(子ども向け)

### 1. 水1てきと水1てきを、くっつけると、水は何てきになる?(数字で答えてね)
*q01 / ひらめき / 記述式*

**正解:1**(ほかに認める答え:1てき、1滴、一)

解説:水てきは、くっつくと、1つの大きな水てきになります。1+1が、いつも2になるとは限らない、というひらめきの問題です。

### 2. 海に面していない県は、次のうちどれ?
*q02 / 社会 / 選択式*

- A. 新潟県
- B. 長野県
- C. 福井県
- D. 千葉県

**正解:B. 長野県**

解説:長野県は海に面していません。海に面していない県は、栃木・群馬・埼玉・山梨・長野・岐阜・滋賀・奈良の8県です。

### 3. 晴れた日の正午ごろ、地面にできるかげの長さは、朝や夕方とくらべてどうなる?
*q03 / 理科 / 選択式*

- A. 朝や夕方より短い
- B. 朝や夕方より長い
- C. 朝や夕方と同じ
- D. かげはできない

**正解:A. 朝や夕方より短い**

解説:正午ごろは太陽がいちばん高い位置にあるので、かげは1日のうちでいちばん短くなります。朝や夕方は太陽が低いので、かげが長くのびます。

### 4. ろうそくが5本、火がついています。風がふいて、2本の火が消えてしまいました。ろうそくは、全部で何本のこっている?
*q04 / ひらめき / 選択式*

- A. 3本
- B. 5本
- C. 2本
- D. 0本

**正解:B. 5本**

解説:消えたのは「火」だけで、ろうそく自体はなくなっていません。火がついているのは3本ですが、ろうそくは5本のこっています。

### 5. かけっこの最中に、あなたは2番目を走っていた人をぬきました。あなたは今、何番目?
*q05 / ひらめき / 選択式*

- A. 1番目
- B. 2番目
- C. 3番目
- D. 4番目

**正解:B. 2番目**

解説:2番目の人をぬくと、その人の場所に入れかわります。だから、あなたが2番目で、ぬかれた人は3番目になります。1番目の人はぬいていないので、1番にはなれません。

### 6. 1本のひもを、まんなかで切ります。できたひもをぜんぶそろえて重ね、また、まんなかで切ります。このように、あわせて3回、まんなかで切ると、ひもは何本になる?
*q06 / ひらめき / 選択式*

- A. 4本
- B. 6本
- C. 8本
- D. 9本

**正解:C. 8本**

解説:1回目で2本になります。2回目は重ねて切るので、ぜんぶ2つに分かれて4本。3回目も同じように2倍になって、8本です。

### 7. 夏に冷たい飲み物を入れたコップの外側に、水てきがつきます。この水は、どこから来た?
*q07 / 理科 / 選択式*

- A. コップの中の飲み物がしみ出した
- B. 氷がとけた水が飛んできた
- C. 空気中の水蒸気が冷やされた
- D. コップが水をつくった

**正解:C. 空気中の水蒸気が冷やされた**

解説:空気中には目に見えない水蒸気がふくまれています。冷たいコップにふれて冷やされると、水てきに変わってコップの外側につきます。

### 8. 1年のうち、30日までしかない月は、2月をのぞくと、4月、6月、9月と、あと1つあります。それは□月です。□に入る数字は?
*q08 / 日常 / 記述式*

**正解:11**(ほかに認める答え:十一、11月、十一月)

解説:30日までの月は、2月をのぞくと、4月・6月・9月・11月の4つです。ほかの月は31日まであります。

### 9. サイコロを ふったら、上の面の目が3でした。下の面の目はいくつ?
*q09 / ひらめき / 選択式*

- A. 2
- B. 3
- C. 4
- D. 5

**正解:C. 4**

解説:サイコロは、向かい合う面の目をたすと7になります。3の反対側は、7-3=4です。

### 10. 次のうち、昆虫ではないのは?
*q10 / 理科 / 選択式*

- A. チョウ
- B. アリ
- C. クモ
- D. カブトムシ

**正解:C. クモ**

### 11. A、B、C、Dの4人が、1列にならんで体育館に入ります。次のことがわかっています。
・AさんはBさんのすぐ前にいる。  
・Dさんは先頭(いちばん前)にいる。  
・Cさんは、いちばん後ろではない。  
前から3番目にいるのはだれ?  
*q11 / ひらめき / 選択式*

- A. Aさん
- B. Bさん
- C. Cさん
- D. Dさん

**正解:A. Aさん**

解説:Dさんが1番目です。Cさんは最後ではないので、2番目か3番目です。「AさんがBさんのすぐ前」なので、AさんとBさんは3番目と4番目になります。すると、Cさんは2番目で、Aさんが3番目、Bさんが4番目です。

### 12. 2枚の硬貨があり、合計は60円です。1枚は50円玉ではありません。2枚の硬貨は何?
*q12 / ひらめき / 選択式*

- A. 50円玉と10円玉
- B. 10円玉と100円玉
- C. どちらも50円玉ではないので、作れない
- D. 10円玉と5円玉

**正解:A. 50円玉と10円玉**

解説:「1枚は50円玉ではない」は、「2枚とも50円玉ではない」という意味ではありません。もう1枚は50円玉でかまいません。だから、50円玉と10円玉です。

### 13. コップのふちまで水を入れて、氷をうかべました。氷がぜんぶとけると、水面はどうなる?
*q13 / 科学 / 選択式*

- A. あふれる
- B. 水面が下がる
- C. 水面が少し上がる
- D. 水面は変わらない

**正解:D. 水面は変わらない**

解説:うかんでいる氷は、自分と同じ重さの水の分だけ水面の下にしずんでいます。とけるとちょうどその分の水になるので、水の高さは変わりません。

### 16. ねこ1匹は、1分でねずみ1匹をつかまえます。ねこ3匹が、ねずみ3匹をつかまえるのに、何分かかる?

### 17. ある月のカレンダーで、たてにならんだ3つの日をたすと、42になりました。まん中の日は何日?
*q17 / ひらめき / 選択式*

- A. 12日
- B. 14日
- C. 15日
- D. 21日

**正解:B. 14日**

解説:たてにならぶ日は、7日ずつちがいます。まん中の日を□とすると、(□-7)+□+(□+7)=□×3です。42÷3=14なので、まん中は14日です。

### 18. お湯がぐつぐつとふっとうしています。火を強くすると、お湯の温度はどうなる?
*q18 / 理科 / 選択式*

- A. 100度のまま
- B. 上がる
- C. 下がる
- D. わからない

**正解:A. 100度のまま**

解説:水は、100度でふっとうして水蒸気に変わります。ふっとうしているあいだ、火を強くしても、お湯の温度は100度のままです。火の力は、水を水蒸気に変えるために使われ、水の量が早くへるだけです。

### 19. 南を上にした地図があります。この地図で、左下にある方角は?

- A. 北東
- B. 北西
- C. 南東
- D. 南西

**正解:A. 北東**

解説:南が上の地図は、北が上の地図を、ぐるりと半回転させたものです。上が南、下が北、右が西、左が東になります。だから、左下は「東」と「北」のあいだの、北東です。

*q21 / ひらめき / 選択式*

### 22. A、B、C、D、E、Fの6人を、背が高い順にならべます。次のことがわかっています。
・AさんはFさんより高い。  
・EさんはAさんより高い。  
・CさんはBさんより高い。  
・FさんはDさんより高い。  
・BさんはFさんより高い。  
・EさんとFさんの間には、ちょうど1人がいる。  
背が高いほうから4番目はだれ?  
*q22 / 論理 / 選択式*

- A. Aさん
- B. Eさん
- C. Bさん
- D. Fさん

**正解:A. Aさん**

解説:AはFより高く、EはAより高いので、E、A、Fの順です。EとFの間にちょうど1人なので、その1人がAです。BはFより高く、Eの上にしかいられません。CはBより高く、DはFより低いので、全体はC、B、E、A、F、Dの順です。4番目はAさんです。

### 23. ふくろが3つあります。「りんご」「みかん」「りんごとみかん」と書いたふだがついていますが、中身とふだはぜんぶまちがっています。1つのふくろから1個だけ取り出して中身を調べるなら、どのふくろから取り出すと、3つの中身がぜんぶわかる?
*q23 / 論理 / 選択式*

- A. 「りんご」のふくろ
- B. 「みかん」のふくろ
- C. どれでも同じ
- D. 「りんごとみかん」のふくろ

**正解:D. 「りんごとみかん」のふくろ**

解説:「りんごとみかん」のふだは必ずまちがいなので、中身はりんごだけかみかんだけです。たとえばりんごが出たら、そのふくろはりんご。すると「みかん」のふだのふくろは(みかんではなく、りんごでもないので)りんごとみかん、残りがみかんだとわかります。

### 24. 鏡にうつった時計が、4時50分をさしているように見えています。実際の時刻は?
*q24 / ひらめき / 選択式*

- A. 8時10分
- B. 4時50分
- C. 7時10分
- D. 5時10分

**正解:C. 7時10分**

解説:鏡では左右が逆になるので、鏡に見える時刻を12時から引くと、実際の時刻になります。12時-4時50分=7時10分です。短い針は、4時50分だと「4」ではなく「5」のすぐ手前にあります。「5」の反対側は「7」なので、実際は8時台ではなく7時台です。

### 25. 深さ10mの井戸の底に、カエルがいます。カエルは、昼に3mのぼり、夜に2mすべり落ちます。カエルが井戸の外に出られるのは、何日目?
*q25 / ひらめき / 選択式*

- A. 10日目
- B. 8日目
- C. 7日目
- D. 9日目

**正解:B. 8日目**

解説:1日で、3m-2m=1mずつ進みます。7日目の夜には7mの高さにいます。8日目の昼に3mのぼると、10mに着いて、夜になる前に外へ出られます。

### 26. ことわざ「枯れ木も山の□わい」の□に入る言葉は?(ひらがなでもいいよ)

**正解:にぎ**(ほかに認める答え:賑)

### 27. 時計が6時を知らせるのに、6回鳴って、はじめの音から最後の音まで5秒かかりました。12時を知らせるときは、12回鳴ります。はじめの音から最後の音まで、何秒かかる?
*q27 / ひらめき / 選択式*

- A. 10秒
- B. 11秒
- C. 12秒
- D. 9秒

**正解:B. 11秒**

解説:6回鳴るあいだに、音と音のあいだは5回あり、5秒かかるので、1回のあいだが1秒です。12回鳴るときは、あいだが11回なので、11秒です。

### 28. はかりの上に、水の入ったコップをのせています。コップにさわらずに、指を1本、水の中に入れました。はかりの数字はどうなる?
*q28 / 理科 / 選択式*

- A. ふえる
- B. へる
- C. 変わらない
- D. 0になる

**正解:A. ふえる**

解説:指を水に入れると、水は指を上におし上げます。その反対に、指は水を下におし返すので、はかりには、そのおし返す力の分が加わって、数字がふえます。

### 29. 北極点に立って、どの方向に歩きはじめても、向かっている方角は?
*q29 / 社会 / 選択式*

- A. 東
- B. 南
- C. 北
- D. 西

**正解:B. 南**

解説:「北」とは、北極点のある方向のことです。北極点に立つと、どの方向へ歩いても、北極点から遠ざかります。それは、北の反対の「南」へ向かうことです。(北極点では、東や西という方角も決まらなくなります。)

### 30. 1、2、3、4の4まいのカードを1列にならべて、4けたの数を作ります。作れる数は、全部で何通り?
*q30 / ひらめき / 選択式*

解説:千の位は4通り、百の位は残りの3通り、十の位は2通り、一の位は1通りです。4×3×2×1=24通りです。

### 31. 見た目が同じ金貨が9枚あります。1枚だけにせ物で、ほかより少し重いです。左右に物をのせて重さをくらべる天びんを使って、にせ物を見つけるには、最低何回はかればよい?
*q31 / ひらめき / 選択式*

### 32. ある2けたの数があります。十の位と一の位の数をたすと7です。十の位と一の位を入れかえると、もとの数より27大きくなります。もとの数は?
*q32 / 数 / 選択式*

- A. 16
- B. 34
- C. 25
- D. 52

**正解:C. 25**

解説:入れかえて大きくなるのは、一の位の方が大きいときです。差の27は9の3倍なので、一の位は十の位より3大きいとわかります。たして7で3の差になるのは2と5。もとの数は25で、入れかえた52との差は27です。

### 33. 夜中の0時ちょうどから次の日の0時の直前までの24時間で、時計の長い針と短い針がぴったり重なるのは何回?(0時ちょうども数えます)
*q33 / 日常 / 選択式*

- A. 24回
- B. 23回
- C. 21回
- D. 22回

**正解:D. 22回**

解説:12時間のあいだに、重なるのは11回です(長針が短針を11回追いこす)。24時間では2倍の22回。0時、1時5分ごろ…と続き、12時にも重なります。

### 34. A、B、Cの3人は、本当のことを言う人か、うそをつく人のどちらかです。Aは「Bはうそつき」、Bは「Cはうそつき」、Cは「AとBはどちらもうそつき」と言いました。うそつきは何人?
*q34 / 論理 / 選択式*

- A. 0人
- B. 1人
- C. 3人
- D. 2人

**正解:D. 2人**

解説:Cが本当だとすると、AもBもうそつきですが、「Bはうそつき」と言ったAがうそつきなら、Bは本当のことになってしまい矛盾します。だからCはうそつきです。するとBの「Cはうそつき」は本当。Bが本当ならAの「Bはうそつき」はうそなので、Aもうそつき。うそつきはAとCの2人です。

### 35. 4人が、夜に橋をわたります。懐中電灯は1つだけで、橋は一度に2人までしかわたれません。2人でわたるときは、おそい人に合わせます。4人がわたるのにかかる時間は、1分、2分、5分、10分です。全員がわたるのに、最短で何分?
*q35 / ひらめき / 選択式*

- A. 17分
- B. 18分
- C. 19分
- D. 20分

**正解:A. 17分**

解説:1分の人と2分の人がわたる(2分)→1分の人がもどる(1分)→5分の人と10分の人がわたる(10分)→2分の人がもどる(2分)→1分の人と2分の人がわたる(2分)。合計17分です。いちばんおそい2人を、いっしょにわたらせるのがコツです。


## オニ問題(表紙のすみのフロリを5回押すと出る)

### オニ1. ある数を3でわると2あまり、5でわると3あまり、7でわると2あまります。いちばん小さい、そのような数は?
*o01 / オニ / 選択式*

- A. 23
- B. 38
- C. 53
- D. 68

**正解:A. 23**

解説:3でわって2あまる数は、2、5、8、11…、5でわって3あまる数は3、8、13、18、23…です。両方にあてはまる最小は8で、これに15をたしていくと、23が7でわって2あまります。

### オニ2. 机の上に21本のぼうがあります。2人が交代で、1〜3本ずつ取ります。最後の1本を取った人が勝ちです。あなたが先に取るとき、最初に何本取れば、必ず勝てる?
*o02 / オニ / 選択式*

- A. 1本
- B. 2本
- C. 3本
- D. どれでも勝てる

**正解:A. 1本**

解説:のこりを、4の倍数にして相手に回すと、相手が何本取っても、あなたが合計4本になるように取れます。21本から1本取って20本にすれば、必ず最後の1本を取れます。

### オニ3. 1番から100番までのとびらが、ぜんぶしまっています。
100人が順番に、とびらを、開いていればしめ、しまっていれば開ける動きをします。  
・1人目は、1の倍数(ぜんぶ)のとびらを動かす  
・2人目は、2の倍数(2、4、6…)のとびらを動かす  
・3人目は、3の倍数(3、6、9…)のとびらを動かす  
…100人目まで、同じように続けます。  
最後に開いているとびらは、何枚?  
*o03 / オニ / 選択式*

- A. 50枚
- B. 25枚
- C. 10枚

**正解:C. 10枚**

解説:とびらは、その番号の約数の数だけ動かされます。約数が奇数のとびらだけが、開いたままです。それは、1、4、9…と、同じ数を2回かけた数で、100までに10こです。

### オニ4. 5人が順番に言いました。A「この中に、うそつきは1人」B「うそつきは2人」C「うそつきは3人」D「うそつきは4人」E「うそつきは5人」。本当のことを言っているのは、だれ?
*o04 / オニ / 選択式*

- A. だれもいない
- B. Bさん
- C. Eさん
- D. Dさん

**正解:D. Dさん**

解説:5人の言葉は、ぜんぶちがう数なので、本当のことを言えるのは、多くても1人です。本当を言う人が1人なら、うそつきは4人。それを言っているのはDさんで、ほかの4人はうそになり、つじつまが合います。

### オニ5. 農夫が、オオカミ・ヤギ・キャベツを、舟で川のむこう岸へわたします。舟には、農夫のほかに1つしか乗せられません。農夫がいないと、オオカミはヤギを、ヤギはキャベツを食べてしまいます。川をわたる回数は、最少で何回?(行きも帰りも1回と数える)
*o05 / オニ / 選択式*

- A. 5回
- B. 7回
- C. 9回
- D. 11回

**正解:B. 7回**

解説:まず、ヤギをわたします(1回)。農夫だけでもどり(2)、オオカミをわたします(3)。オオカミをおろして、ヤギを連れてもどります(4)。キャベツをわたして(5)、農夫だけでもどり(6)、ヤギをわたします(7)。全部で7回です。
