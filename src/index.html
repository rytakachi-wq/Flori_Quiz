        ルール

        木をおすと、その木と上下左右の木が1つずつ育つヨ。

        🌱芽 → 🌿枝 → 🌳木 → 🌸桜の木

        桜の木の次は芽にもどるヨ。

        全部を🌸桜の木にしたらクリア!

        解くコツ

        1. 上の段から順にそろえる。上の木を育てたいときは、その「すぐ下」の木をおす。
        2. 同じ木は3回までで十分。4回おすと、もとにもどるヨ。
        3. 下の段にそろわない木が残ったら。上の段の木を何個かおして、もう一度上から順にやり直す。
        4. 行きづまったら「ヒント」。光る木をおしてみよう。
